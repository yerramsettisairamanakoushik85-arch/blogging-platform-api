\# Blogging Platform API



A simple RESTful blogging API built with Python, Flask, and SQLite.



\## Features



\- Create blog posts

\- Get all posts

\- Get a single post

\- Update posts

\- Delete posts

\- Search posts by title, content, or category

\- SQLite database



\## Run



```bash

pip install -r requirements.txt

python app.py
